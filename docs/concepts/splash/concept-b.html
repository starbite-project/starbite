Starbite · S-Boot splash · Concept B

One wordmark,
one quiet line.

The splash says only what is true at power-on: this is Starbite, on a Galaxy S9. The wordmark carries the screen alone; the device line sits a full step below it in system grey, the way iOS sets a secondary label.

SAMSUNG is gone: it is Samsung's mark, not ours, and a second wordmark is what made the earlier splashes busy. “Galaxy S9” stays as plain text. It names the hardware, and it returns as the menu's status-bar label, so it never really leaves.

Each element is its own band on pure black, placed where the v7 intro expects it. The wordmark crosses row 1232, so the loader glides it into the glass island. The star is a separate band that hands its light to the wallpaper star. The device line rises and fades with the splash text.
