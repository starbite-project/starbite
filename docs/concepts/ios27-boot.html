Choose a System

The whole Galaxy S9 boot, designed as if Apple shipped it: the S-Boot splash, a Liquid Glass intro, giant glass provider sections that spring open, options, auto-start, launch and failure. The glass is rendered for real in WebGL: refraction from a continuous-corner distance field, edge light, specular that follows the pointer, dispersion at the rims, and a multi-tap frosted wallpaper under every pane.

Options

Renderer–
Spec
Static vs dynamic. Static after the intro: the wallpaper (star included) and its two blur levels (A ½ res σ ≈ 26 px, B ¼ res σ ≈ 60 px). Bake them once at boot, or ship them as images. Dynamic, per frame: only the pixels inside each glass shape plus a 110 × 150 px shadow margin. A frame is a list of at most 20 rounded rects (x, y, w, h, radius, alpha, tint, strength, flags clip/lens/frost) and one light vector. The light only changes on pointer or accelerometer input. There is no idle drift and the dither is a fixed pattern, so when nothing moves no frame is drawn (signature check). Glass refracts the wallpaper only, never text. The intro is the only time the wallpaper itself changes (star flight, bloom, reveal) and the only time the SAMSUNG height field (650 × 110 A8, blurred r 3 twice) is sampled.

Glass shader

Shapesuperellipse corner n = 2.6, radius × 1.18 (continuous corner); capsules blend to n = 2
Bezelbez = clamp(0.8·r, 16, 64) px; e = clamp(1 + d/bez, 0, 1); lens profile bend = 1 − √(1 − e²)
Refractionsample at p + n · bend · bez · 1.3 · strength (n = outward SDF normal; panes 1.0, tiles 0.9, launch 1.15, lens 1.4)
DispersionR at +8·bend·strength px, B at −8, from blur A
Frost5 taps on A (centre 0.36, ±12 px diagonals 0.16 each), mixed toward B by max(0.75·size, 0.92·frost, 0.8·soft); size = smoothstep(300, 900, min(w, h))
Vibrancysaturation 1.45 (frosted 1.2), gain 1.10, lift +0.014, then mix(col, tint·(0.42 + 1.3·L), tintAlpha); clear panes +0.016 milk inside the bezel
Edge lightrim = emin(d,0)/max(2, 1.1k); × (0.07 + 0.60·max(n·L,0)² + 0.32·max(−n·L,0)²); inner band 0.03 + 0.08·max(n·L,0) times bend; far side darkened 14%
Speculargaussian lobe at centre + L·half-size·0.6, 4.5%; L = normalize(−0.45 + 0.9·tx, −0.9 + 0.6·ty), tilt from the pointer (accelerometer on device)
Shadowoffset y 24, e−d/48, 32%
Focus lenssame glass, strength 1.4, passes 82% of what is under it × 1.07; stretches 3% of its y velocity
Overlaymenu scales to 0.965, CSS blur 26 px, brightness −25%; base glass softens (feathered edge, blur B); overlay backdrop 45% black

Porting to the S9

Framebuffer1440 × 2960 ARGB8888 (S-Boot / DECON format), 17.0 MB per frame; double-buffer and flip, or copy dirty rects only
Colour spacesRGB-encoded 8-bit values; every mix and blend is done on the sRGB values (gamma space), as the browser does, so the device matches this prototype. Linear blending would make the rims brighter, so do not switch.
Ditherfixed ±0.5/255 hash pattern by pixel position, never animated
Software pathPre-bake one frosted, tinted wallpaper per tint, since pane interiors (bend = 0) are static. Refraction and dispersion run only in the 16–64 px rim band. Replace pow() per pixel with per-radius corner tables for distance and normal (straight edges are trivial). Composite per scanline with NEON over dirty rects. Target 30 fps.
Full-screen cardsthe launch card touches every one of the 4.26 Mpx, so in software let it settle at 30 fps; 60 fps comes with the Mali-G72 (one fragment pass, scissor rects)
TextA8 coverage atlases pre-rasterised at the fixed sizes: Inter Tight 700 at 142/128/100/92/70, 600 at 66/58/46; Inter 400–600 at 56/50/48/44/42/38/33; JetBrains Mono 500 at 40/36/34. Latin-1 plus · → ≈ ’ “ ”; about 1.6 MB total. Tiles and icons are pre-rendered RGBA at 124, 172, 220 and 380.
Springsm = 1, k = (2π/response)², c = 4πζ/response; semi-implicit Euler (v += a·h, then x += v·h) with h = 4 ms sub-steps inside each frame; settle when |x − target| < ε and |v| < 8ε
Inputskeys from the PMIC/GPIO (Volume, Power, Bixby); hold timers 520 ms (Power) and 700 ms (Bixby); touch from the digitizer as tap, long-press 480 ms and drag
