# T83 / T83b: do both rows boot the right driver? (2 boots, ~20 min each)

Needs the selector installed and its test log on (sbwddm-ng-0169/INSTALL.md), and the row `win11-ng` in the store.
The stage is T61's driver set (what the standard rows run) + gputest: sb-user.bat (= starbite/win/autotest/
sb-rows.bat), sbcomp, sbshow, sb-gd.bat + sb-click.ps1, GL kit 0169 (opengl32-gd.dll, libgallium_wgl-gd.dll).

```
S=~/project-starbite/build/win/stage; R=~/project-starbite/build/win/results-t83
tools/win/sbsel-install.sh log on $R
tools/win/gpu-cycle.sh $S/sbwddm-t83 $R/ng  --test-key win11-ng  --full-sec 1800 --no-trace --keys 1 --afbc 0
tools/win/crash-report.sh $R/ng
tools/win/gpu-cycle.sh $S/sbwddm-t83 $R/std --test-key win11-big --full-sec 1800 --no-trace --keys 1 --afbc 0
tools/win/crash-report.sh $R/std ; tools/win/user-pull.sh $R/std/user
(the usual restore: install-default T61, gd-kit-push gd-kit-ec-0158, orient 4)
tools/win/sbsel-install.sh log off $R
```
## PASS (pre/gputest/gputest.log of each)
| | T83 `ng` (row win11-ng) | T83b `std` (row win11-big) |
|---|---|---|
| row signal | `ROWS WtDat 63476 = row NEW-GPU` (63477 also fine) | `ROWS WtDat 65063 = row standard` |
| selector | `ROWS VERDICT PASS`, the `ROWS DWM:` line ends `-> sbumd-ng.dll` | `ROWS VERDICT PASS`, DWM `-> sbumd.dll` |
| desktop | `ROWS DWM SURVIVED`, sbcomp lines name "Starbite Display" | the same |
| game | the game driver's `row: new GPU` line, zero-copy, present thread on | "no zero-copy lines (= the GDI present path)" |

## If it goes wrong
- `ng` shows `row standard` with WtDat 65063: the firmware or loader did not pass 80 s through. Harmless (the row
  ran the standard driver); the signal needs another carrier. Tell me, skip nothing else.
- Either boot has no gputest.log, or "Microsoft Basic Render Driver" in the sbcomp lines, or `NO DRIVER LOADED` in
  sbsel.log: the selector itself is at fault. `tools/win/sbsel-install.sh restore $R` at once, then the usual
  restore; the standard rows are then exactly as before the install.
